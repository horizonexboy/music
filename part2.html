CACTI (MONITORING SERVER) ============================ ============================================================ RUNBOOK INSTALASI CACTI MONITORING SERVER Ubuntu Server + MikroTik Router ============================================================ TUJUAN ------ Instalasi Cacti dari Ubuntu Server baru untuk memonitor: 1. Ubuntu Server melalui SNMP. 2. MikroTik gateway Ubuntu melalui SNMP. KONFIGURASI LAB --------------- OS : Ubuntu Server 26.04 LTS Cacti : Paket repository Ubuntu Web server : Apache2 Database : MariaDB RRDtool : RRDtool SNMP : SNMP v2c Timezone : Asia/Jakarta (WIB) IP MikroTik : 192.168.30.1 IP Cacti Server : Sesuaikan dengan IP server Interface : Sesuaikan, contoh enp0s3 COMMUNITY SNMP -------------- Ubuntu Server : cactiLabRO MikroTik : mikrotikRO CATATAN ------- - DNS, domain, dan konfigurasi VirtualHost tidak dibahas karena sudah dikonfigurasi secara terpisah. - Kerjakan bertahap. Tes di runbook ini hanya tes dasar. Jika ada masalah, baru lanjutkan troubleshooting. - Sesuaikan versi PHP, IP server, dan nama interface dengan hasil instalasi masing-masing. a. PERSIAPAN UBUNTU ------------------- Update sistem: sudo apt update sudo apt upgrade -y Atur timezone: sudo timedatectl set-timezone Asia/Jakarta Periksa jaringan: ip -br a ip route Pastikan Ubuntu mendapat IP yang benar dan default gateway: 192.168.30.1 b. INSTALASI PAKET CACTI ------------------------ Install paket: sudo apt install apache2 mariadb-server rrdtool snmp snmpd cacti Saat prompt instalasi muncul: Configure database for Cacti with dbconfig-common? Pilih: Yes Cacti application password: Isi password yang ingin digunakan untuk login Cacti, lalu masukkan kembali saat diminta konfirmasi. Simpan password tersebut. Prompt password berikutnya untuk user administratif/root MySQL atau MariaDB: Biarkan kosong, lalu lanjutkan. Web server: Pilih Apache2 jika diminta. Catatan: Password login Cacti berbeda dari password database. Ikuti urutan prompt yang tampil pada installer paket Ubuntu. c. LOGIN AWAL CACTI ------------------- Buka alamat Cacti yang sudah disiapkan sendiri. Login: Username : admin Password : password Cacti yang dibuat saat instalasi Setelah berhasil masuk, pastikan dashboard tampil normal. d. TIMEZONE PHP --------------- Cek versi PHP: php -v Contoh berikut menggunakan PHP 8.5. Ganti nomor versi jika versi yang terpasang berbeda. Edit konfigurasi PHP Apache: sudo nano /etc/php/8.5/apache2/php.ini Atur: date.timezone = Asia/Jakarta Edit konfigurasi PHP CLI: sudo nano /etc/php/8.5/cli/php.ini Atur: date.timezone = Asia/Jakarta Restart Apache: sudo systemctl restart apache2 e. KONFIGURASI SNMP UBUNTU -------------------------- Backup konfigurasi: sudo cp /etc/snmp/snmpd.conf /etc/snmp/snmpd.conf.bak Edit: sudo nano /etc/snmp/snmpd.conf Pastikan directive aktif berikut tersedia: agentaddress udp:127.0.0.1:161 rocommunity cactiLabRO 127.0.0.1 Jika directive serupa sudah ada, sesuaikan yang aktif dan hindari konfigurasi ganda. Restart dan aktifkan SNMP: sudo systemctl enable --now snmpd sudo systemctl restart snmpd TES DASAR SNMP UBUNTU --------------------- snmpwalk -v2c -c cactiLabRO 127.0.0.1 .1.3.6.1.2.1.1 Jika informasi sistem Linux muncul, SNMP Ubuntu merespons. f. TAMBAHKAN UBUNTU SEBAGAI DEVICE ---------------------------------- Di Cacti: Console > Management > Devices > Add Isi: Description : ubuntu Hostname : 127.0.0.1 Device Template : Net-SNMP Device SNMP Version : Version 2 SNMP Community : cactiLabRO SNMP Port : 161 Simpan device dan pastikan informasi SNMP terbaca. g. BUAT GRAPH UBUNTU -------------------- Buka device Ubuntu: Create Graphs for this Device Pada Graph Templates, pilih template yang diperlukan, misalnya: - CPU Utilization - Memory Usage - Load Average - Uptime Pada Data Query: SNMP - Interface Statistics Pastikan interface terdeteksi, misalnya lo dan enp0s3. Jika belum muncul: - Refresh/reload Data Query. - Jika masih gagal, buka debug mode untuk melihat penyebabnya. - Setelah query berhasil, refresh halaman Create Graphs. Untuk grafik bandwidth: 1. Pilih interface fisik, contoh enp0s3. 2. Jangan pilih lo karena itu loopback. 3. Pilih Graph Type: In/Out Bits. 4. Klik Create. In/Out Bits menampilkan traffic masuk dan keluar dalam bit per detik. h. KONFIGURASI SNMP MIKROTIK ---------------------------- MikroTik yang menjadi gateway Ubuntu: IP Address : 192.168.30.1 Community : mikrotikRO Aktifkan SNMP melalui Winbox: IP > SNMP Langkah: 1. Aktifkan SNMP. 2. Tambahkan community bernama mikrotikRO. 3. Gunakan SNMP v2c. 4. Batasi alamat sumber ke IP Cacti Server. 5. Terapkan konfigurasi. PENTING: Ganti dengan alamat IP Ubuntu yang sebenarnya. Jangan membuka akses SNMP ke semua alamat jika tidak diperlukan. Contoh melalui terminal RouterOS: /snmp set enabled=yes /snmp community add name=mikrotikRO addresses=/32 Jika community default public tidak diperlukan, nonaktifkan atau hapus sesuai kebijakan konfigurasi router. Pastikan firewall MikroTik mengizinkan UDP port 161 dari IP Cacti Server menuju router. i. TAMBAHKAN MIKROTIK SEBAGAI DEVICE CACTI ------------------------------------------ Di Cacti: Console > Management > Devices > Add Isi: Description : MikroTik-Gateway Hostname : 192.168.30.1 Device Template : Generic SNMP-enabled Host SNMP Version : Version 2 SNMP Community : mikrotikRO SNMP Port : 161 Jika tersedia template MikroTik yang sesuai, template tersebut juga dapat digunakan. Jika tidak, mulai dengan Generic SNMP-enabled Host. Simpan device. TES DASAR KONEKSI MIKROTIK -------------------------- Dari Ubuntu: ping -c 4 192.168.30.1 Tes SNMP: snmpwalk -v2c -c mikrotikRO 192.168.30.1 .1.3.6.1.2.1.1 Jika informasi sistem router muncul, SNMP berhasil merespons. j. BUAT GRAPH MIKROTIK ----------------------- Buka device MikroTik: Create Graphs for this Device Pilih graph template yang tersedia dan/atau Data Query interface jika terdeteksi. Untuk grafik bandwidth: 1. Pilih interface MikroTik yang ingin dipantau. 2. Pilih Graph Type: In/Out Bits. 3. Klik Create. Nama interface dapat berupa ether1, ether2, bridge, atau nama lain sesuai konfigurasi router. k. GRAPH TREE -------------- Buka: Console > Management > Trees 1. Pilih Default Tree. 2. Masuk ke mode Edit Tree. 3. Tambahkan Root Branch, misalnya: Ubuntu Server MikroTik Gateway 4. Masukkan graph yang sesuai ke masing-masing branch. 5. Klik Finish Editing Tree. Buka tab Graphs > Tree View untuk melihat grafik. Jika tampilan Tree atau grafik terlihat kosong, periksa zoom browser. Tekan Ctrl + 0 untuk mengembalikan zoom ke 100%. Preview View dapat digunakan untuk memeriksa graph tanpa bergantung pada susunan Graph Tree. l. POLLER DAN PENGUMPULAN DATA ------------------------------- Periksa cron: sudo systemctl status cron Periksa jadwal Cacti: sudo cat /etc/cron.d/cacti Interval umum/default adalah 5 menit. Pastikan Poller Interval di pengaturan Cacti sesuai dengan jadwal cron. Jangan membuat cron poller tambahan sebelum memeriksa konfigurasi bawaan paket agar tidak menjalankan poller ganda. Tunggu beberapa siklus polling, lalu periksa apakah grafik mulai menampilkan data.
